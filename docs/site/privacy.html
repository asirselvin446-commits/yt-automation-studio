Privacy Policy

YT Automation Studio · Last updated: 17 September 2026

YT Automation Studio ("the app") is a personal tool that helps its owner publish their own videos to their own YouTube channel. This policy explains what data the app handles.

Who runs this app

This app is operated by an individual for personal use. Contact: asirselvin446@gmail.com.

Information the app accesses

  • Google/YouTube account access (via Google OAuth): to read basic channel information and to upload videos to the account owner's own YouTube channel, using the YouTube Data API.
  • Video files that the owner explicitly chooses to process, along with metadata generated from them (title, description, tags, transcript).

How information is used

Data is used solely to analyze the owner's videos and publish them to the owner's YouTube channel. The app does not use Google user data for advertising, and does not sell or share it with third parties.

Storage and security

  • OAuth tokens are stored encrypted in the owner's own private Supabase project and are used only to act on the owner's behalf.
  • Video files are stored only temporarily during processing and are deleted after the upload completes.
  • Transcription and metadata generation use the Google Gemini API.

Google API Services disclosure

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and removal

The owner can revoke the app's access at any time at Google Account permissions, which stops all further access. Stored tokens and processing data can be deleted from the owner's Supabase project at any time.

Changes

This policy may be updated; the date above reflects the latest version.
